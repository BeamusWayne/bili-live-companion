首次公开发布，提供 Windows x64 独立 EXE，以及新版 B 站粉白桌面界面。

### 下载与使用

下载下方 **BiliCompanion-v0.1.0-Windows-x64.exe**，双击运行，无需安装 Python。扫码登录 → 保存账号 → 输入直播间 → 识别任务 → 开始。

附件同时提供 Windows 使用说明、SHA-256 校验值和打包启动检查结果。源码可使用 GitHub 自动生成的 Source code 下载。

### 本次更新

- 新增 Windows 打包、一键构建和自动发布流程。
- 使用 B 站小电视图标，重做侧栏、账号管理、任务进度、设置、日志与扫码窗口，减少重复说明文字。
- 支持多账号、托盘和单实例唤醒，Windows 凭据由本机 DPAPI 加密。
- 窗口、更新检查和 EXE 属性统一为 v0.1.0。

### 验证与已知限制

- 发布前运行 Windows 桌面测试，并验证打包 EXE 的窗口、导航、图标、时区和 DPAPI 读写。
- 真实扫码、观看计时和奖励领取仍需有效账号与当前活动实测，任务结果以 Bilibili 返回为准。
- EXE 尚未进行代码签名。本次仅提供 Windows x64 二进制；macOS 桌面版与 Linux 服务端提供源码和运行说明，未提供本次验证的对应安装包。
